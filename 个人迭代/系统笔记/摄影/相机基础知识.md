# 相机基础知识

> 相机拍摄分三件事：**曝光、对焦、色调**。曝光是光圈·快门·感光度三个量的组合，对焦是「对焦区域 × 对焦模式」的选择，色调课程尚未展开。整理自相机附赠课程「相机基本使用」（[[2026-09-27]]），首次用于实践见 [[2026-09-28]]。

| --- | --------------- | --------------------------------- |

## 二、曝光：光圈 · 快门 · 感光度

### 1. 光圈

- **F 后面的数字越小，光圈越大**，进光量越多，画面越亮。
- 特性：**光圈越大，背景虚化效果越好**，可以突出主体。

### 2. 快门

- 快门相当于**这张照片的持续时间**——它决定相机收集多长的光。
- 双重作用：不仅可以调曝光，还可以**记录这一段时间里光的轨迹**。

### 3. 感光度 ISO

- **高感光度 → 提高图片的噪点；低感光度 → 噪点更少、画质更高。**
- 取舍规则：**高快门**或**长焦镜头**时曝光不足，可以**适当提高 ISO 来补曝光**——用噪点换快门速度。

### 4. 拍摄模式与测光模式

- 相机的各种拍摄模式，本质就是**对这三个量做排列组合**。
- 机身能读出**进光量是否合适、偏移了多少**：因为有一个**感光标准**做基准，才谈得上"偏移"——所以有了**测光模式**。
- 测光模式常见两种：**全景模式**、**点测光**。

> 课程的例子（原话）：要突出主体，拍人逆光，如果用全景测光的话，会把人平均到非常暗，所以用点测光。

### 5. 曝光补偿：白加黑减

|      档位      | 看什么 / 调什么                          |
| :----------: | ---------------------------------- |
| 曝光监测<br>（M 档） | 机身只显示**偏移了多少**，要改就得自己动那三个量          |
|     其他模式     | 有**曝光补偿**，拨补偿即可，机身自己去配平三个量         |

**原则：白加黑减。**

- **白加**：背景是白色，相机觉得很亮了，会把测光调低 → 人物反而被压暗，所以需要**增加**曝光补偿来保持人物的亮度。
- **黑减**：背景是暗的，相机会把测光调高 → 不能还原真实的亮度，所以需要**降低**曝光补偿。

> 批注（原话保留）：课程里说的是「全自动 M 档」，按上下文应指全手动的 M 档——M 档只能看测光标尺偏移，P/A/S 等档位才用曝光补偿配平。待对照机身校准。

## 三、对焦

对焦定两件事：**对焦区域**（合焦落在哪）＋**对焦模式**（用什么方式合焦）。

### 1. 对焦区域

从最小到全部，范围可大可小（课程的表述：范围越来越大或者越来越小的自动对焦，或者全部自动对焦）：

|    对焦区域    | 范围  | 适用              |
| :--------: | --- | --------------- |
|   定点对焦     |  最小 | （待补充）           |
|   单点对焦     |      | （待补充）           |
|   区域对焦     |  较大 | （待补充）           |
|  全部自动对焦    |  全部 | 交给相机自己判断         |

### 2. 对焦模式：AF / MF

- **AF 自动对焦**，分三种：

|    模式     | 拍什么        | 特点                        |
| :-------: | ---------- | ------------------------- |
|  单次自动对焦   | 静止物体       | **单次精准度最高**              |
|  伺服自动对焦   | 移动物体       | 持续跟踪对焦                    |
|  人工智能对焦   | 毫无征兆的物体    | 在单次与伺服之间**自动切换**，应对突发情况的平衡选择 |

- **MF 手动对焦**，两种情况下用：
  1. **进光量比较多、自动对焦困难**的时候，可以尝试手动对焦
  2. 需要**特殊效果**的时候

> 批注（原话保留）：「进光量比较多」这条待校准——按前面光圈那节推，应为光圈开大后进光多、景深极薄，合焦面太窄所以 AF 难；也存在是弱光场景的可能。实拍验证后再定。
