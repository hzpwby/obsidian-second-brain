# 最低系统使用指南

> 第二大脑砍到最低可运转后的实际用法。面向自己，也是 AI 除了框架文档外了解「这个系统实际在跑什么、我每天怎么用」的入口。
>
> 系统设计哲学见 [[焦虑茧房]]——只留最低限度能运转的秩序，其余全部交给主体性。冗余不是必须，只是可以更好。

---

## 六个需求维度

### 1. 睡眠

| 维度 | 内容 |
|------|------|
| 需求 | 睡眠是最重要的减负项 |
| 采集 | 日复盘 `**睡眠时长**: X` + `**清醒感受**: 文字` |
| 可视化 | Home.canvas 睡眠折线图（蓝色） |
| 文件 | `日志/日复盘/YYYY-MM-DD.md`、`🏠Home.canvas` |

### 2. 冥想

| 维度   | 内容                         |
| ---- | -------------------------- |
| 需求   | 学习并实践冥想，与健身、音乐同类           |
| 采集   | 日复盘里无需采集，**休息不能工具化**       |
| 系统笔记 | `个人迭代/系统笔记/冥想/冥想.md`       |
| 数据库  | `个人迭代/笔记目录/系统笔记目录/冥想.base` |
### 3. 饮食

| 维度  | 内容                       |
| --- | ------------------------ |
| 需求  | 自己做饭，省钱、健康、好吃            |
| 采集  | 日复盘 `迭代复盘·菜谱` 板块记录当日做饭内容 |
| 框架  | `个人迭代/` 下菜谱框架文档          |
| 实盘  | 菜谱文件夹，记录并迭代学会的菜谱         |
### 4. 健身

| 维度 | 内容 |
|------|------|
| 需求 | 身体训练，长期迭代 |
| 采集 | 日复盘 `系统迭代` 下 `- [ ] 健身打卡` checkbox + `迭代复盘·健身` 表格记录每组动作 |
| 可视化 | Home.canvas 健身热力图（绿色，看频率） |
| 体重追踪 | 日复盘 `**体重**: X` → Home.canvas 体重折线图 + 当日进度汇总（`当前进度 {{(sum()-61)/2*100::.1f}}%`，目标 65kg，起始 58kg，差距 7kg） |
| 系统笔记 | `个人迭代/系统笔记/健身/`（健身重启策略、练肩、练胸等） |
| 数据库 | `个人迭代/笔记目录/系统笔记目录/健身.base` |

### 5. 音乐（迭代学习）

| 维度   | 内容                                                  |
| ---- | --------------------------------------------------- |
| 需求   | 音乐练习，长期迭代                                           |
| 采集   | 日复盘 `系统迭代` 下 `- [ ] 练琴打卡` checkbox + `迭代复盘·音乐` 记录练习内容 |
| 可视化  | Home.canvas 练琴热力图（橙色）                               |
| 系统笔记 | `个人迭代/系统笔记/音乐/音乐.md`（骨架已建，待填充）                      |
| 数据库  | `个人迭代/笔记目录/系统笔记目录/音乐.base`                          |

### 6. 个人迭代（笔记架构 + 待办）

| 维度        | 内容                            |
| --------- | ----------------------------- |
| 需求        | 知识内化与学习                       |
| **待处理笔记** | 接收新知识，尚未提炼                    |
| **常青笔记**  | 已内化的清晰认知（`#识` 标签待长期验证后升 `#道`） |
| **系统笔记**  | 某个学习体系的结构化笔记（健身、音乐、冥想等）       |
| **图书馆**   | 学习新东西的地方                      |

流转规则见 [[复盘迭代框架#反思分流：复盘如何回流知识库]]。

**待办事项与起念**：

| 文件               | 用途                    | 归集机制                                                         |
| ---------------- | --------------------- | ------------------------------------------------------------ |
| **系统迭代待办**       | 系统迭代任务（健身、音乐等），一个系统一个大标题 | 同上                                                           |
| **（自己添加大项目）待办**  | 大项目待办留白示范：大项目摘出来单独建档   | 同上                                                           |
| **起念**           | 随性所欲的行动想法，不同于其他待办的计划性 | Tasks 查询 `path includes 起念`，不强制带日期                           |

> 起念与其他待办的区别：其他待办是计划性的（有明确截止日期），起念是「我想做但没确定什么时候做」的行动池。不怕忘记事情，也不用惦记——写下来就放下。

## 状态分级（重启指标）

> 2026-08-21设计。级别＝容量声明，不是方向决策：每级列的都是「哪怕不上班也要完成的事」，主攻与探索不进级别、走每晚「增量」。一级为底往上叠加；状态不对就降级——**日中降级合法，降级后完成的当天依然算系统在运转**。一级生存 · 二级生活 · 三级训练 · 四级满配。

### 通用条目（每一级都含）

| 条目 | 判定 |
|------|------|
| 睡眠 | 固定 **7:00 起床**（闹钟，白班晚班同锚——时钟稳定优先于时长达标）；反推 **22:00-23:00 熄灯**保 8-9 小时带；**24:00 是底线不是目标**（「游戏/下载不拖过12点」）；熄灯后不碰手机；突发情况可临时平移入睡点，但时长优先——睡眠第一位，其他一切让路。实际时长照记日志当数据，不作判定 |
| 早晨数据 | 起床后填当日日志：体重（晨起空腹）、昨夜睡眠时长、清醒感受、资金 |
| 洗漱 | 早晚各一次 |

### 四级阶梯（每级完整清单，直接复制进明日任务）

> 判定细则以 [[#通用条目（每一级都含）]] 为唯一来源；下面每级是完整勾选清单，定级后整块复制进明日任务。

**一级 · 生存（4 项）**
```
- [ ] 睡眠锚：7:00 起 ＋ 22:00-23:00 熄灯（24:00 底线）＋ 熄灯后不碰手机
- [ ] 早晨数据：体重 / 睡眠时长 / 清醒感受 / 资金
- [ ] 洗漱：早晚各一次
- [ ] 早饭：必吃（可买可做）
```
> 无精力就不做饭——没有别的了，这就是底。

**二级 · 生活（8 项）**

- [ ] 早晨数据：体重 / 睡眠时长 / 清醒感受 / 资金
- [ ] 洗漱：早晚各一次
- [ ] 早饭：必吃（可买可做）
- [ ] 三餐自做（上班没时间，午饭或晚饭可外卖一顿；有改进顺手优化菜谱）
- [ ] 冥想 · 早（5-10 分钟，做了就算）
- [ ] 冥想 · 回家（5-10 分钟）
- [ ] 冥想 · 睡前（5-10 分钟）
```

**三级 · 训练（9 项）**

- [ ] 早晨数据：体重 / 睡眠时长 / 清醒感受 / 资金
- [ ] 洗漱：早晚各一次
- [ ] 早饭：必吃（可买可做）
- [ ] 三餐自做（上班没时间，午饭或晚饭可外卖一顿；有改进顺手优化菜谱）
- [ ] 冥想 · 早（5-10 分钟，做了就算）

**四级 · 满配（10 项）**
```
- [ ] 睡眠锚：7:00 起 ＋ 22:00-23:00 熄灯（24:00 底线）＋ 熄灯后不碰手机
- [ ] 早晨数据：体重 / 睡眠时长 / 清醒感受 / 资金
- [ ] 洗漱：早晚各一次

- [ ] 三餐自做（上班没时间，午饭或晚饭可外卖一顿；有改进顺手优化菜谱）

> 当前暑假暂停期，实际在一级二级运转；9/1 健身练琴恢复后，三级四级解锁。

### 工作日通用补充（有班的日子，任何级）

最低限度讲解即可；学生笨，不生气、不较真，尊重他人命运，尽力即可。

### 定级仪式（睡前，两问一落笔）

1. **明天几级？**——看明天班次日程 ＋ 今晚状态
2. **明天的增量是什么？**——主攻/学习/想做的事的最小动作；可以为零，零也要说出口；有余力就做，没完成零负担
3. **落笔**：在明日任务写「明日状态：X级」，把该级清单整块复制进去逐项勾选，增量单列一条

> 级别是地板，不是鞭子。真想做的事不需要鞭子，不想做的事不该被鞭子抽。想看约束力，周复盘看本周级别分布和增量兑现率——用数据照镜子，不增实体。

## 一天的典型流程

1. **7:00 起床**（闹钟，白班晚班同锚）→ Templater 自动生成当日日复盘 `YYYY-MM-DD.md`
2. **早晨数据**（一级起的硬要求）：填 `**体重**: X`（晨起空腹才有效）、`**睡眠时长**: X`（昨夜）、`**清醒感受**:`、`**攒的钱**: X`、`**流动资金**: X`
3. **白天做事**：按当前级别执行——洗漱、吃饭、冥想、训练按级；有班的日子按工作日通用补充。待办任务带 `📅 当天日期` 自动出现在「今日任务」，级别项目和增量就在里面勾；起念里的想法随时记
4. **睡前**：
   - 在 `迭代复盘` 区记录当日各维度干了什么；勾选 `系统迭代` 下的健身/练琴
   - 每日复盘：AI 协助整理当日总结与反思（结论/完成的/改进/正向）
   - **定级仪式**：两问一落笔——①明天几级 ②明天的增量——写进「明日任务」，改进项写成 Tasks 复选框指向明天，形成跨天闭环
5. **反思分流**（按需）：清晰认知→常青笔记/系统笔记，模糊想法→待处理笔记/起念

## 系统迭代点（可选，不是必须）

最低系统使用指南，所有流程都跑通了，除了这个最低限度，其他的都是系统可以升级迭代的点，但不是必须的选项，所以，现在你已经拥有了一个**很不错的下限**，脚踏实地，一步一步踩实往前走吧

> 观念支撑：[[焦虑茧房]]——「不进步也活得活得下去」。系统已经满足要求、能运转了，这些迭代点只是可以更好。
