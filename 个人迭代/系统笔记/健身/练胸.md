# 练胸

> 胸部训练以卧推类动作为核心，关键在于底部拉伸幅度与念动一致的夹胸发力感。

## 平板哑铃卧推

### 一、动作流程

#### 1. 准备姿势

- **下沉肩胛**：平躺后双肩向后向下沉，肩胛骨后收下贴在凳面上**不锁死**。肩胛骨往中间靠拢下沉，
- **腰部自然拱起**：下背微离凳面，形成自然弓形，稳定躯干、减少肩关节压力。注意是自然弓形，非刻意反弓。
- **脚踩地面做支撑**：全脚掌着地，提供腿驱动支点，稳定身形。
 - **护腕**：卧推>80% 1RM（自身体重）或者有伤和疼痛辅助一下。
#### 2. 推起阶段

- 想象**胸部发力夹胸**推起哑铃（念动一致），感觉**二头向胸部靠拢**（关键）
- 肩前束和肱三头肌必然参与辅助，关键是胸主导发力，不耸肩、**肩胛不外展往前送，不紧绷肩前束**（肩部压力大）
- **呼吸**：推起时吐气

#### 3. 顶峰收缩

- 肘关节**不锁死**，两侧哑铃**不碰撞**。锁死 = 张力转移到骨骼关节，胸肌卸力；碰撞 = 发力中断，动作变形。保持胸肌持续张力，推起终点即下一次离心的起点。

#### 4. 下落阶段

- **离心控制**：想象背部主导将哑铃往背后拉，肩胛骨自然后收下沉，**拉伸胸部**。 
- 前臂始终保持垂直地面（侧面看），大臂与躯干夹角约 45°-60°，小了练手臂，大了练肩前束。
- **大臂小臂形成直角**时即到底部，不过度弯曲，不前臂后倒
- **底部幅度**：沿头脚方向（人体纵向），肘略低于肩。这个幅度让胸大肌获得**更深的拉伸**，直接关联增肌效果。**前提：肩关节无不适时执行；如有不适则缩减幅度**。
- 动作底部停顿约 1 秒，感受胸肌的拉伸张力
- 避免借力弹起，确保张力由肌肉承受而非牵张反射
- **呼吸**：下落时吸气

---

### 二、关键机制

#### 1. 拉伸介导增肌

肌肉在**被拉长的位置承受张力**时，会触发额外的增肌信号，不依赖传统的向心/离心收缩路径。这是近年肌肥大研究的核心发现之一。

| 层面 | 解释 |
|------|------|
| 基本概念 | 肌肉在拉伸位承受负荷 → 激活机械敏感信号通路 → 促进肌节串联增加 → 肌肉纵向增长 |
| 与传统增肌的区别 | 传统增肌依赖代谢压力（泵感）和肌肉微损伤；拉伸介导增肌走的是机械张力信号，一条独立通路 |
| 为什么卧推底部有效 | 底部时胸大肌处于最大拉长位，停顿让拉伸张力持续作用，无牵张反射干扰，是胸肌增肌的高效窗口 |
| 哑铃 vs 杠铃的优势 | 哑铃卧推的底部幅度比杠铃更大（无横杆限制），胸大肌拉伸更深，拉伸介导效应更充分 |

**判断**：大臂略低于肩（更深的拉伸幅度）+ 底部停顿（更久的拉伸张力）放在一起，对胸肌增肌是 1+1>2 的效果——两条不同增肌通路的叠加。

### 三、常见错误

| 错误             | 纠正                   |
| -------------- | -------------------- |
| 大臂与肩持平（肘过高）    | 大臂降至略低于肩，前臂垂直地面      |
| 落底后弹起借力        | 底部停顿 1 秒再推           |
| 推起时肩前束绷紧，刻意往前送 | 肩胛自然联动，只想**二头向胸部靠拢** |
| 下背完全贴凳（无弓形）    | 自然弓形，腰部微离凳面          |

## 上斜哑铃卧推

> 与平板哑铃卧推动作要领基本一致，核心差异在于**上斜角度侧重上胸**。

- 凳面调至 30°-45°，角度过高会更多转到三角肌前束
- **准备姿势、推起、顶峰收缩、下落** 四大环节与平板卧推相同
- 常见错误及前束代偿机制同上，见 [[#平板哑铃卧推]]
