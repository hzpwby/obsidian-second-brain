# 爆炒油麦菜

## 用料
| 材料   | 用量         | 图示  | 备注  |
| ---  | ---------- | --- | --- |
| 油麦菜 | 两把         | [[个人迭代/菜谱/菜谱附件/爆炒油麦菜/油麦菜.jpg\|油麦菜]] |     |
| 大蒜  | 大块头 5 个左右 | [[个人迭代/菜谱/菜谱附件/爆炒油麦菜/大蒜.jpg\|大蒜]]   |     |

## 步骤

| 步骤  | 详情  | 图示  | 备注  |
| :-: | --- | --- | --- |
|  ①  | 洗好油麦菜控干水分                                          |     | 一定要控干水分          |
|  ②  | 油麦菜切成3段，根部放盘中，其他两段备用；盘中放上蒜蓉和干辣椒                    |     |                  |
|  ③  | 盘中加一勺食盐                                            | [[个人迭代/菜谱/菜谱附件/爆炒油麦菜/步骤3.jpg\|步骤3]] |                  |
|  ④  | 半勺食盐，用开水化开                                        |     |                  |
|  ⑤  | 油烧热，将盘中准备好的根部、调料以及稀释的盐水一起倒入锅中；翻拌10秒左右，根部稍软即可        |     |                  |
|  ⑥  | 放入菜叶翻拌至成熟即可出锅                                       |     | 家用厨具温度稍低，不用反复翻拌。加入菜叶后不超过1分钟即可出锅 |
