## 步骤

| 步骤  | 详情                                                | 图示                                                                | 备注                                           |
| :-: | ------------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------- |
|  ①  | 水烧开，五花肉焯水 2 分钟左右，捞出切成小块                           |                                                                   | 不然太油腻                                        |
|  ②  | 倒少许油烧热润锅，倒入五花肉煸炒 15 分钟左右，盛出备用                     | [[个人迭代/菜谱/菜谱附件/红烧肉/煸炒五花肉.jpg\|煸炒五花肉]]                             | 多余油脂可用来炒土豆                                   |
|  ③  | 下土豆炒至焦黄，盛出备用                                      |                                                                   |                                              |
|  ④  | 剩余油加入少许冰糖炒糖色                                      | [[个人迭代/菜谱/菜谱附件/红烧肉/步骤四.jpg\|步骤四]] [[个人迭代/菜谱/菜谱附件/红烧肉/糖色.jpg\|糖色]] | 利用余温控制颜色程度，太深会发苦                             |
|  ⑤  | 倒入五花肉翻拌均匀，使肉裹上糖色                                  |                                                                   |                                              |
|  ⑥  | 放入葱姜蒜、桂皮八角香叶；加两锅铲生抽、半锅铲老抽、一锅铲料酒；加入没过食材的开水，焖煮 1 小时 |                                                                   | **焖煮期间每 10 分钟看一次并翻动，防粘锅糊底** |
|  ⑦  | 加入土豆翻炒，焖煮 10 分钟；大火收汁，撒入葱花即可                       |                                                                   | 期间注意不要把水烧干了                                  |
