# Tasks 任务时间安排插件

> 版本：当前适用 | 路径：命令面板 → Tasks: Create or edit task

---

## 核心功能

Tasks 是 Obsidian 的任务管理插件，支持任务优先级、截止日期、重复周期、依赖关系等高级功能。与原生任务列表相比，Tasks 提供了更丰富的任务属性和可视化界面。

---

## Create or edit Task 界面详解

按 `Ctrl+P` 打开命令面板，搜索 "Tasks: Create or edit task" 打开任务创建/编辑窗口：

### 1. Description（描述）

| 项目 | 说明 |
|------|------|
| 作用 | 任务的名称和具体内容 |
| 格式 | 纯文本，支持 Markdown 格式 |
| 示例 | `复习初中数学第3章` |

---

### 2. Priority（优先级）

| 级别 | 图标 | 含义 |
|------|------|------|
| **Highest** | ⏫ | 最高优先级，必须立即处理 |
| **High** | 🔼 | 高优先级，尽快完成 |
| **Normal** | 无 | 普通优先级（默认） |
| **Low** | 🔽 | 低优先级，有空再做 |
| **Lowest** | ⏬ | 最低优先级，可推迟 |

**使用建议**：配合 [[复盘迭代框架#每日复盘改进项自动流转]]，改进项建议设为 High 或 Highest 确保优先执行。

---

### 3. Recurs（重复周期）

| 输入格式 | 含义 |
|----------|------|
| `every day` | 每天重复 |
| `every week` | 每周重复 |
| `every month` | 每月重复 |
| `every year` | 每年重复 |
| `every weekday` | 工作日重复（周一至周五） |
| `every 3 days` | 每3天重复一次 |

**当前系统使用场景**：健身、练琴等习惯追踪任务使用 `- [ ]` checkbox + Tracker 热力图，不依赖 Tasks 的重复功能。

---

### 4. 时间相关字段

#### Due（截止日期）📅
- **含义**：任务必须完成的最后期限
- **用法**：`📅 2026-06-25` 格式
- **显示**：逾期任务会在日复盘的「⚠️ 逾期未完成」区块自动标出

#### Scheduled（计划日期）⏳
- **含义**：计划在哪一天执行这个任务
- **用法**：`⏳ 2026-06-25` 格式
- **区别**：Due 是 deadline，Scheduled 是 intent

#### Start（开始日期）🛫
- **含义**：任务最早可以开始的日期
- **用法**：`🛫 2026-06-25` 格式
- **场景**：提前安排，但到日期前不显示在今日任务中

#### Only future dates（仅未来日期）
- **作用**：勾选后，日期选择器只能选择今天及以后的日期

---

### 5. 依赖关系

#### Before this（前置任务）
- **含义**：此任务依赖的其他任务（必须先完成前置任务）
- **用法**：搜索并选择前置任务

#### After this（后置任务）
- **含义**：依赖此任务的其他任务（完成此任务后才能做后置任务）
- **用法**：搜索并选择后置任务

**当前系统使用场景**：教学备课流程可用此功能，如「下载大纲」→「编写教案」→「课堂使用」形成依赖链。

---

### 6. Status（状态）

| 状态 | 符号 | 说明 |
|------|------|------|
| **Todo** | `[ ]` | 待办（默认） |
| **In Progress** | `[/]` | 进行中 |
| **Done** | `[x]` | 已完成 |
| **Cancelled** | `[-]` | 已取消 |

---

### 7. 时间戳字段

#### Created（创建时间）➕
- **含义**：任务创建的时间
- **符号**：`➕ 2026-06-25`

#### Done（完成时间）✅
- **含义**：任务完成的时间
- **符号**：`✅ 2026-06-25`
- **自动**：勾选任务后自动记录

#### Cancelled（取消时间）❌
- **含义**：任务取消的时间
- **符号**：`❌ 2026-06-25`

---

### 8. 操作按钮

| 按钮 | 作用 |
|------|------|
| **Apply** | 应用设置，生成任务代码块 |
| **Cancel** | 取消操作，不保存 |

---

## 任务语法速查

在笔记中直接写任务时，使用以下符号：

```markdown
- [ ] 任务描述 🔼 ⏳ 2026-06-25 📅 2026-06-26
```

| 符号 | 含义 | 位置 |
|------|------|------|
| `🔼` `⏫` | 优先级 | 任务后 |
| `📅` | Due（截止） | 日期后 |
| `⏳` | Scheduled（计划） | 日期后 |
| `🛫` | Start（开始） | 日期后 |
| `➕` | Created（创建） | 日期后 |
| `✅` | Done（完成） | 日期后 |
| `❌` | Cancelled（取消） | 日期后 |

## 与复盘系统的联动

### 日复盘自动归集

[[复盘迭代框架#每日复盘改进项自动流转]] 中使用了 Tasks 的核心机制：

```markdown
- [ ] 改进项描述 📅 2026-06-26
```

- 当日写的改进项带 `📅 明天日期`
- 次日日志的「📋 今日任务」自动归集
- 勾选完成 → 进入「✅ 今日完成」
- 形成跨天闭环

### CSS 隐藏任务标签

为保持日复盘界面简洁，使用 CSS 片段隐藏 Tasks 的任务标签：

```css
/* 隐藏日期标签（S0、TS、D2026-05-12 等） */
.task-scheduled,
.task-start,
.task-due,
.task-done,
.task-cancelled,
.task-created {
  display: none !important;
}
```

详见 [[复盘迭代框架#CSS 片段]]。

## 常见问题

### Q1: 任务不自动出现在今日任务中？

**检查清单**：
1. 是否加了 `📅` 日期符号？**必须加**
2. 日期是否为今天或之前？
3. 任务是否被勾选完成？已完成的不显示

### Q2: 如何快速创建任务？

**方案**：
- 命令面板：`Ctrl+P` → "Tasks: Create or edit task"
- 快捷语法：直接写 `- [ ] 任务 📅 日期`

### Q3: 重复任务怎么设置？

**方案**：在 Recurs 字段输入 `every day`、`every week` 等。

**当前系统替代方案**：习惯追踪使用 checkbox + Tracker 热力图（见 [[Tracker数据可视化插件]]），不依赖 Tasks 重复功能。
