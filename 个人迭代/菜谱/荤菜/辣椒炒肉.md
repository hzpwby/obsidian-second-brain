## 步骤

| 步骤  | 详情                                     | 图示                                 | 备注                    |
| :-: | -------------------------------------- | ---------------------------------- | --------------------- |
|  ①  | 锅不放油不放水，螺丝椒下锅煸炒，盛起备用                   | [[个人迭代/菜谱/菜谱附件/辣椒炒肉/步骤1.jpg\|步骤1]] |                       |
|  ②  | 倒少许油，烧热润锅；再倒冷油，下五花肉炒至几乎变色带微深，盛起备用      | [[个人迭代/菜谱/菜谱附件/辣椒炒肉/步骤2.jpg\|步骤2]] | 不可久炒                  |
|  ③  | 下油，放葱姜蒜炒香                              |                                    |                       |
|  ④  | 放老干妈炒出红油                               |                                    |                       |
|  ⑤  | 五花肉回锅，加**少许**生抽、老抽、蚝油，加半勺盐、半勺味精，快速翻炒均匀 |                                    | 盐和味精各小半勺，绝不能超过半勺，超了就咸 |
|  ⑥  | 放入辣椒，大火快炒，辣椒吸收到汁即可盛出                   |                                    | 不可久炒                  |
