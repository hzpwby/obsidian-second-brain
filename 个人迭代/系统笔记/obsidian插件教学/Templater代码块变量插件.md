# Templater 插件设置说明

> 版本：当前适用 | 路径：设置 → Templater

---

## 一、核心设置（Template Settings）

### 1. Template file location
- **含义：** 指定模板文件夹路径
- **建议值：** `模板/`
- **说明：** 按 Ctrl+P 运行 "Templater: Insert template" 时，插件会从这个文件夹列出所有可用模板

### 2. Trigger Templater on new file creation
- **含义：** 新建文件时是否自动触发 Templater
- **建议：** ✅ 开启
- **说明：** 开启后，用 Obsidian 新建文件时如果文件名匹配规则，会自动套用模板

### 3. Automatic templates
- **含义：** 设置文件创建时自动套用的模板规则
- **用法：** 可以添加多条规则，规则格式为：
  - 适用文件夹：哪些文件夹下的新文件触发
  - 模板文件：自动套用哪个模板

---

## 二、文件夹模板（Folder Templates）

| 设置 | 说明 |
|---|---|
| **Folder** | 指定文件夹路径，该文件夹下的新文件会触发自动模板 |
| **Template** | 选择要自动套用的模板文件 |

示例：
```
文件夹：日志/日复盘     → 自动套用：日志模板.md
文件夹：个人迭代/菜谱   → 自动套用：菜谱模板.md
```

---

## 三、空模板设置（Empty File Template）

### Enable Empty File Template
- **含义：** 新建空白文件时，是否自动插入内容模板
- **建议：** 保持关闭
- **说明：** 如果你希望新建文件时自动插入一段固定内容（比如 frontmatter），可以开启并指定模板

---

## 四、语法（Syntax Highlighting）

### Syntax Highlighting
- **含义：** 是否高亮 Templater 语法（`<% %>` 区域）
- **建议：** ✅ 开启
- **说明：** 开启后模板代码区域会有颜色标记，方便区分普通内容和模板代码

---

## 五、常用 <% tp 语法速查

| 语法 | 作用 | 示例输出 |
|---|---|---|
| `<% tp.date.now("YYYY-MM-DD") %>` | 插入当前日期 | 2026-05-15 |
| `<% tp.date.now("HH:mm") %>` | 插入当前时间 | 14:30 |
| `<% tp.file.title %>` | 插入当前文件名 | 2026-05-15 |
| `<% tp.file.folder() %>` | 插入当前所在文件夹 | 日志/日复盘 |
| `<% tp.system.prompt("输入内容") %>` | 弹窗让你手动输入 | （弹窗） |
| `<%* tR += "自定义文字" %>` | 插入自定义文字 | 自定义文字 |

## 六、和 Obsidian 自带模板的关系

| | 自带模板 | Templater |
|---|---|---|
| 代码块内替换 | ❌ | ✅ |
| 弹窗输入 | ❌ | ✅ |
| 条件判断 (if/else) | ❌ | ✅ |
| 循环生成 | ❌ | ✅ |
| 执行 JavaScript | ❌ | ✅ |
| 学习成本 | 零 | 低（基础语法 5 分钟） |

对于你目前的需求，只需要知道 `<% tp.date.now("YYYY-MM-DD") %>` 这一个语法就够了。
