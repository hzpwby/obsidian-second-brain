# 番茄炒蛋

## 用料
| 材料  | 用量        | 图示                               | 备注               |
| --- | --------- | -------------------------------- | ---------------- |
| 番茄  | 拳头大，1-2 个 | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/番茄.jpg\|番茄]] |                  |
| 鸡蛋  | 3-4 个     | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/鸡蛋.jpg\|鸡蛋]] |                  |
| 配料  |           |                                  | 生抽、老抽、盐、白糖，陈醋、淀粉 |

## 步骤

| 步骤  | 详情                      | 图示                                                     | 备注                                |
| :-: | ----------------------- | ------------------------------------------------------ | --------------------------------- |
|  ①  | 烧开水，番茄烫后剥皮              | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/步骤1.jpg\|步骤1]]                     |                                   |
|  ②  | 番茄切成小碎块                 | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/步骤2.jpg\|步骤2]]                     | 一定要碎，容易出汁                         |
|  ③  | 鸡蛋打散，加 1/3 勺盐搅匀         | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/步骤3.jpg\|步骤3]]                     | 要搅拌很充分，起泡泡，混合在一起                  |
|  ④  | 热油，下鸡蛋煎至微焦，盛起备用         | [[个人迭代/菜谱/菜谱附件/番茄炒蛋/步骤4.jpg\|步骤4]]<br>[[步骤5.jpg\|步骤5]] | 油一定要热，稍微多一点即可，太多了会晕，可以蓬松，不可过老，薄一点 |
|  ⑤  | 少油，下番茄，加一点盐逼出水分，炒至微微出汁  |                                                        | 加一点水，快速成汁                         |
|  ⑥  | 加少许老抽、少许生抽，翻拌           |                                                        | 锅边淋入，激发香气                         |
|  ⑦  | 加少许盐、白糖、陈醋（白糖这时候比盐多一点）  |                                                        | 少许即可白糖 1/3 勺，鸡蛋已经加盐了              |
|  ⑧  | 加淀粉水，收汁                 |                                                        | 一平勺                               |
|  ⑨  | 鸡蛋回锅，弄成小块，加小半勺味精，翻拌均匀即可 |                                                        |                                   |
