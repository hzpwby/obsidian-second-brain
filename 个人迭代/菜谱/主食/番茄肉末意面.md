## 步骤

| 步骤  | 详情 | 图示 | 备注 |
| :-: | --- | --- | --- |
|  ①  | 肉末加少许生抽、老抽、盐、淀粉、料酒、蚝油腌制，再用少许食用油封水 |  |  |
|  ②  | 意面不盖锅盖，煮 11 分钟 |  |  |
|  ③  | 锅下少许油烧热润锅，再倒冷油下肉末；微微变色下大蒜翻炒；下洋葱和番茄（切小块），加少量番茄酱 |  | 番茄一定要切小块 |
|  ④  | 调好料汁：生抽 3 勺、老抽 1 勺、蚝油少许、糖半勺、淀粉 2 勺、少许清水，搅拌调匀 |  |  |
|  ⑤  | 倒入调好的料汁，煮到稍微粘稠 |  |  |
|  ⑥  | 放入意面，筷子搅拌吸收汤汁；加入芝士片 |  | 两人份 3 片；水量少粘锅可加少量水 |
|  ⑦  | 盛起装盘 |  |  |
