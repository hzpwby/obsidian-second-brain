# 可乐鸡翅

## 用料
| 材料  | 用量        | 图示                               | 备注                   |
| --- | --------- | -------------------------------- | -------------------- |
| 鸡翅  | 10 个      | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/鸡翅.jpg\|鸡翅]] |                      |
| 可乐  | 淹没鸡翅即可    |                                  |                      |
| 大蒜  | 大个头 5 个左右 | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/大蒜.jpg\|大蒜]] |                      |
| 生姜  | 两指体积      | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/生姜.jpg\|生姜]] |                      |
| 大葱  | 四指宽，切条    | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/大葱.jpg\|大葱]] |                      |
| 配料  |           |                                  | 盐、老抽、生抽、料酒、白糖、白芝麻、小葱 |

## 步骤

| 步骤  | 详情                                                      | 图示                                 | 备注                |
| :-: | ------------------------------------------------------- | ---------------------------------- | ----------------- |
|  ①  | 冷水解冻鸡翅，鸡翅改刀                                             |                                    |                   |
|  ②  | 倒少许油烧热润锅，再倒冷油，调小火；一次煎五个鸡翅，煎至两面金黄，盛起备用                   | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/步骤2.jpg\|步骤2]] | 油多一点不会粘锅          |
|  ③  | 加少许油，放入葱姜蒜，炸香即可                                         |                                    |                   |
|  ④  | 鸡翅回锅；加半勺盐、1/3 锅铲老抽、1/4 锅铲生抽、少许料酒、少许白糖；倒入可乐，淹没即可；盖上锅盖，中火 | [[个人迭代/菜谱/菜谱附件/可乐鸡翅/步骤4.jpg\|步骤4]] | 盖锅盖焖不超过 10 分钟，会粘锅 |
|  ⑤  | 大火收汁，快速翻拌至料汁成型                                          |                                    |                   |
|  ⑥  | 盛起摆盘，撒入少许小葱、白芝麻                                         |                                    |                   |
