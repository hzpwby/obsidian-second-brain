# 第二大脑 · 通用版（Obsidian）

一套开箱即用的 Obsidian 个人知识管理系统：包含日志复盘、待办事项、模板与知识框架、个人迭代（图书馆 / 菜谱 / 常青笔记）等模块，通过 🏠Home Canvas 作为统一入口导航，帮助把碎片信息沉淀为结构化的个人知识库。

## 快速开始

1. 点击本页绿色 **Code** 按钮 → **Download ZIP**，解压到任意位置；
2. **重要**：把文件夹「（要把这个文件夹括号和括号里删掉）.obsidian」改名为 `.obsidian` —— 它保存了主题、插件和全部配置，不改名 Obsidian 将无法识别；
3. 安装 [Obsidian](https://obsidian.md)（免费），打开后选择「打开文件夹作为仓库」，选中解压出的文件夹；
4. 主页 🏠Home Canvas 会作为统一入口，从那里进入各个模块；
5. 图文详细教程见仓库中的 `第二大脑使用说明_压缩版.html`，用浏览器打开即可。

## 目录结构

| 路径 | 内容 |
|---|---|
| 🏠Home.canvas | 主页导航入口（Canvas 画布） |
| 日志 | 日复盘 / 周复盘 / 月复盘 / 年复盘 及目录索引 |
| 待办事项 | 工作、架构、系统迭代等各类待办 |
| 框架 | 各模块的设计框架与总论 |
| 模板 | 日志、复盘、书摘、菜谱等笔记模板 |
| 附件 | 图片等附件 |
| 个人迭代/图书馆 | 书摘、书籍笔记、书籍目录与封面附件 |
| 个人迭代/菜谱 | 菜谱笔记与成品/配料照片 |
| 个人迭代/常青笔记 · 系统笔记 · 笔记目录 · 待处理笔记 | 个人知识迭代模块 |
| .obsidian | Obsidian 配置（插件、主题、快捷键） |
