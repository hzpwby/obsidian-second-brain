# 练肩

> 肩部训练以推肩为核心动作，侧平举（飞鸟）和俯身飞鸟分别覆盖中束和后束，三者覆盖三角肌前、中、后三束。

## 哑铃推肩

### 一、动作流程

#### 1. 准备姿势

- **握位平衡**：**无名指**握在哑铃握杆中间，保持重心不偏。
- **脚踩实地，核心收紧**：双脚全脚掌踩实地面，核心微收，为坐姿推举提供稳定底座。避免下肢松垮导致上身晃动。
- **哑铃角度**：哑铃不要完全垂直于地面，保持轻微倾斜70°，更贴合肩关节自然力线。
- **腰背紧贴靠背**：**背部紧贴凳面**，腰部自然弯曲。身体不可与靠背悬空——悬空会导致腰部借力代偿。若凳子靠背角度达不到约 70°-80°，可垫哑铃片调整。
- **手腕中立**：手腕与地面垂直，不前屈不后掰。保持中立位，让哑铃的力完整传导至整个手臂。
- **肘部内收，哑铃呈八字**：手肘往身体斜前方适当内收，不平行打开。哑铃从上方看呈八字形，减少肩关节压力，力线更集中。

#### 2. 推起阶段

- 想象**三角肌发力**将哑铃往上推（念动一致），不是单纯把重量顶上去。
- **轨迹**：哑铃推起时略向头顶方向走弧线，不是垂直直线。弧线更贴合肩关节在肩胛面的自然运动轨迹。
- 向上推起时沉肩，**不耸肩、不锁死肩胛肩胛骨**（会导致肩峰撞击）
- **呼吸**：推起时吐气
#### 3. 顶峰收缩

- 顶部**手臂不完全伸直锁死**。锁死 = 张力从三角肌转移到骨骼关节，直接卸力。保持三角肌持续张力。

#### 4. 下落阶段

- 下落时保持张力，离心匀速控制
- **底部幅度**：大臂略低于肩膀即可，不过度下放。若肩关节活动度或力量不足，降至与肩平行甚至更少皆可，以无痛为底线。
- **呼吸**：下落时吸气

---

### 二、关键机制

**肩胛面推举**：肩关节在矢状面（正侧面）推举时，肩峰下空间变窄，容易引发撞击。将肘部前移约 30°，肩峰下空间增大，力线更安全。这就是肘部内收、哑铃呈八字的力学依据。

**拉伸介导增肌**：与卧推同理，底部大臂略低于肩时三角肌前束处于拉长位，停顿让拉伸张力充分作用。但推肩的底部幅度比卧推保守——肩关节结构决定了它不适合追求极限拉伸，以无痛范围为界。详见 [[练胸#1. 拉伸介导增肌]]。

---

### 三、常见错误

| 错误           | 纠正             |
| ------------ | -------------- |
| 腰部悬空借力       | 背部紧贴靠背，核心收紧    |
| 肘关节完全平行打开    | 肘部斜前方内收，哑铃呈八字  |
| 推起时耸肩，顶峰还往上送 | 自然肩胛联动，感受三角肌主导 |
| 顶部手臂锁死       | 微屈肘，保持三角肌持续张力  |
| 底部下放过深       | 大臂略低于肩即可，无痛为底线 |
| 手腕后掰         | 手腕中立，与前臂呈直线    |

## 哑铃飞鸟

### 一、动作流程

#### 1. 准备姿势

- **半握**：握哑铃用**半握**（拇指不扣紧），减少前臂借力。
- **微屈肘**：手臂不完全伸直，保持肘关节微屈，避免锁死。
- **沉肩**：**肩胛骨**下沉**自然联动**，**不锁死**（肩峰撞击），全程不耸肩。
- **上肢微俯身**：身体不前倾到跟地面平行，也不完全直立，微微前倾让**力线更集中在中束**。

#### 2. 上抬阶段

- **节奏**：上抬时快速爆发，下放时缓慢控制（快起慢下）。
- 想象将哑铃往身体两侧**甩出去**，而不是用手臂提起来。驱动点在大臂/肘部，手只是握住的工具。
- **呼吸**：上抬时吐气

#### 3. 顶峰收缩

- 哑铃抬至与肩同高即可，**不越过肩膀**。越过肩 = 斜方肌上束接管，中束卸力。
- 顶峰停顿约 1 秒，保持三角肌中束张力。肘关节始终微屈，不锁直。

#### 4. 下放阶段

- 缓慢下放，感受三角肌中束在离心阶段的持续张力。不要直接掉落。下放到最低点时**不完全放松**，**保持肌肉张力不卸力**，为下一次上抬蓄力。
- **呼吸**：下放时吸气

---

### 二、关键机制

**长力臂动作**：哑铃飞鸟手臂基本伸直时，哑铃离肩关节轴心远，力臂极长。**小重量**即可产生大刺激，这也是侧平举不能用大重量的力学原因。借力甩起会缩短力臂，反而降低中束刺激。

**肩峰下撞击保护**：手臂完全伸直 + 哑铃越过肩 + 手臂内旋三者叠加，会压缩肩峰下空间，造成撞击。微屈肘、不越肩，肩胛自然联动正是为了保护肩关节。

**中束孤立**：三角肌中束无法被推肩有效覆盖，只能靠侧平举孤立刺激。这决定了**动作规范比重量重要**——不规范 = 中束没练到。

---

### 三、常见错误

| 错误       | 纠正         |
| -------- | ---------- |
| 肩胛锁死     | 自然联动，不过度沉肩 |
| 手臂完全伸直   | 微屈肘，保持固定角度 |
| 哑铃越过肩膀   | 与肩同高即停     |
| 身体完全直立   | 上肢微俯身      |
| 下放到底完全放松 | 底部保持张力不卸力  |
| 借力甩起     | 快起慢下，离心控制  |
| 全握握法     | 半握，减少前臂借力  |
