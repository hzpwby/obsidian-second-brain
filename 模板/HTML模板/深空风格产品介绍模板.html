SECTION 2 · 卡片与流程

深空卡片的三种内件

卡片 .card 是全文档的主体容器——内放主题标签、说明条、列表、流程线、数据流块。

卡片样例一 · 标签＋说明条＋列表

这是一句话说明条（.role）——概括这张卡片讲什么。

  • ▸ 普通条目：最常用；em 是青色强调，行内代码用 code 样式。
  • 绿色对勾条目（li.ok）——表示已完成 / 已确认的事。
  • 琥珀待办条目（li.todo）——表示还没做的事。
  • 紫色进行中条目（li.wip）——表示正在做。

卡片样例三 · 数据流 / 目录树

.dataflow 等宽字体块——流程图、目录树都用它；行尾琥珀备注用 span.d（← 说明、▼ 步骤）。注意：源码里的换行和缩进会原样渲染。

SECTION 3 · 小节横幅

章节内的小节划分

一章内用 h4.part 分小节——绿色横幅＝已定稿内容，琥珀横幅（加 .todo）＝待办内容。

✓ 第一部分 · 已定稿小节占位

小节标题占位
  • 要点一：正文占位——写清这件事的规则或结论。
  • 要点二：正文占位——一篇文档由「hero → 若干章节 → 页脚」组成。

◇ 第二部分 · 待办小节占位

待办条目占位
