## 步骤

| 步骤  | 详情                                                    | 图示                                 | 备注                                |
| :-: | ----------------------------------------------------- | ---------------------------------- | --------------------------------- |
|  ①  | 锅内不放油不放水，螺丝椒下锅煸炒，盛起备用                                 | [[个人迭代/菜谱/菜谱附件/青椒炒蛋/步骤1.jpg\|步骤1]] |                                   |
|  ②  | 鸡蛋打散，加 1/3 勺盐搅拌                                       | [[个人迭代/菜谱/菜谱附件/青椒炒蛋/步骤2.jpg\|步骤2]] |                                   |
|  ③  | 热油，下鸡蛋煎至微焦，盛起备用                                       | [[个人迭代/菜谱/菜谱附件/青椒炒蛋/步骤3.jpg\|步骤3]] | 油一定要热，稍微多一点即可，太多了会晕，可以蓬松，不可过老，薄一点 |
|  ④  | 放少许油，大蒜大葱炸香；倒入螺丝椒，稍微翻炒；加少许生抽、老抽、蚝油、少许白糖，少许盐、少许香油，快速翻拌 |                                    | 快速翻拌，均匀即可                         |
|  ⑤  | 鸡蛋回锅弄成小块，翻拌均匀即可                                       |                                    | 快速翻拌，均匀即可                         |
|  ⑥  | 倒入少量油，快速翻炒即可出锅                                        |                                    | 润滑不干巴                             |
