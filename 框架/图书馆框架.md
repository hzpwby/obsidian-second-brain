## 一、图书馆文件架构

| 路径               | 用途                                                  |
| ---------------- | --------------------------------------------------- |
| `个人迭代/图书馆/`      | 根目录                                                 |
| `个人迭代/图书馆/书籍文件/` | 电子书实体文件（统一 PDF）                                        |
| `个人迭代/图书馆/书籍/`   | 每本书一篇 Markdown 笔记（元数据卡片），内联链接引用实体文件                 |
| `个人迭代/图书馆/书摘/`   | 阅读过程中的高亮、批注、摘抄笔记                                    |
| `个人迭代/图书馆/书籍附件/` | 书籍封面图片                                              |
| `个人迭代/图书馆/书籍目录/` | Bases 数据库（`书籍目录.base`，卡片视图管理所有书籍）                  |

> 具体文件列表以实盘为准。AI 操作时先读取 `个人迭代/图书馆/` 最新目录结构，不以本框架中的静态示例为准。

**原则**：
- 实体文件集中放在 `书籍文件/`，与元数据笔记同层级，结构紧凑
- 书摘笔记与元数据笔记分离：元数据在 `书籍/` 里给数据库索引，书摘在 `书摘/` 里供阅读记录沉淀

**附件**：书籍封面放在 `个人迭代/图书馆/书籍附件/`，在书籍笔记 YAML 的 `cover` 字段中引用，Bases 卡片视图自动读取。

> **不需要异常处理**：所有文件已同步云端，PDF 不会损坏，书摘不会丢失。

## 二、书籍来源

本地电子书文件**不限格式**：PDF 直接入库；EPUB / MOBI / AZW3 / TXT 等只要能转成文字版 PDF，同样可入库（详见 [[#2.3 来源不限 PDF]]）。书站在墙外需代理访问。

### 2.1 渠道清单（2026-09 实测）

| 渠道 | 当前入口 | 用途 | 注意 |
| --- | --- | --- | --- |
| Anna's Archive | annas-archive.gl / .pk / .gd（旧域名 .org/.li 已失效） | 聚合搜索入口，一次搜全网索引 | 搜索有 DDoS-Guard，须真浏览器；免费下载走 Slow Partner Server（Fast 通道需付费会员），慢速直落、自动存盘无需人工点保存 |
| LibGen | libgen.li | 直链下载主力 | 503 常见（等待重试）；搜索页 JS 渲染 |
| 豆瓣 | book.douban.com suggest API | 封面 + 元数据 | 请求需带 Referer 和浏览器 UA |
| Z-Library | z-library.sk | libgen 没有的书 | 免费账号登录才能下载 |
| Internet Archive | archive.org | 老书 / 台版 | 多为借阅制，直下受限 |

> 域名与反爬机制随时变，渠道打不开即为过时信号，重测后更新本表。

### 2.2 找书三步

1. **搜**：Anna's Archive 搜一次（聚合全网）。搜不到 → 换关键词再搜（作者名 / 繁体书名 / 英文原名 + 中文语言过滤）。仍无 → 走判定原则
2. **下**：只取**文字版**文件（EPUB / MOBI / AZW3 / 文字 PDF，判定见 [[#2.3 来源不限 PDF]]），PDF 候选超 30MB 即图片层、跳过换源。按优先级取文件：libgen 直链（curl 最快）→ 浏览器下载（触发系统保存对话框，**需人工点一次保存**）→ 需账号渠道（看值不值）
3. **归**：验文件头 → 验体积（PDF 须 ≤30MB）→ 非 PDF 先转 PDF（见 [[#2.3 来源不限 PDF]]）→ 按命名规范 `[国籍]作者 - 书名 (年份, 出版社)`（中文作者不带国籍前缀）存入 `书籍文件/` → 笔记「文件位置」回链 → 豆瓣拿封面存 `书籍附件/`

### 2.3 来源不限 PDF

找书时**不限定 PDF**，但**只收文字版**。判定标准两条：**① 最终能不能变成文字版 PDF；② 体积不是图片级（≤30MB）**。

**体积上限 30MB**（2026-09 实测：馆内文字版 PDF 0.7–12MB，扫描版 399MB。30MB 给文字版约 2.5 倍余量，同时低于一切图片层/混合层）：

- 下载前预筛：候选是 PDF 且 >30MB → 判为图片层，跳过换源
- 入库前实测：最终 PDF ≤30MB，超标不入库
- EPUB / MOBI 源文件体积不限（内嵌图片可能大），以转换后 PDF 实测为准
- 图片层**没有无损失转换法**：保原图的双层 PDF（扫描图+隐藏 OCR 层）体积不变；OCR 重排体积虽小但版面重造、错字残留。故图片层不转不收，一律另找文字版

| 找到的格式 | 处理 |
| --- | --- |
| PDF（文字版） | 直接入库 |
| EPUB / MOBI / AZW3 | 转成 PDF 后入库。EPUB 本身是文字版，解压即取文本，转换效果最好 |
| TXT / DOCX / HTML | 转成 PDF 后入库，需补排版（标题层级、分页、页码） |
| PDF（扫描件） | **不入库**：即使补了 OCR 文字层，体积仍是图片级。按无文字版资源处理，另找文字版；全网确无文字版时才考虑 OCR 重排（有损：版面重排、错字残留），须在书籍笔记备注 |

**转换后删除原始格式文件**，`书籍文件/` 内只留 PDF。理由：库内格式统一，Obsidian 与 AI 都只需处理一种格式，不出现同一本书两个文件并存。

**命名不变**：转换出的 PDF 仍按 `[国籍]作者 - 书名 (年份, 出版社)` 命名，与直下的 PDF 毫无差别，笔记回链、封面、数据库流程完全一致。

**转换后自检**（全部通过再删原始文件）：体积 ≤30MB → 文本可抽取（能选中、能搜索）→ 页数与原书一致 → 有书签可跳章 → 目录页码指向真实页码 → 封面正常显示。

> 转换是一次性操作，中间产物不留库内。

### 2.4 判定原则（何时停手）

| 情形                 | 判定                         |
| ------------------ | -------------------------- |
| 平台独占网文（番茄小说 / 起点等） | 直接判死，笔记记正版渠道               |
| 出版 1-2 年内的新书       | 公开库常无电子版 → 官方渠道 + 备注"定期复查" |
| 老书简体搜不到            | 繁体 / 英文版也算无资源              |

**原则**：不主动囤货。看到想读的录入数据库（待读），需要时再找 PDF。
## 三、单本书笔记格式

每本书一篇 Markdown 笔记（用 `模板/书籍模板.md` 新建，单一事实源——框架不内嵌模板全文），YAML frontmatter 只存核心元数据，其余放正文，字段说明见下表。

### 数据库字段说明

Bases 自动读取 `书籍/` 文件夹下所有笔记的 YAML frontmatter。

| 字段    | 类型  | 说明                          |
| ----- | --- | --------------------------- |
| 书名    | 文本  | 笔记标题                        |
| 作者    | 文本  |                             |
| cover | 附件  | 封面图片（见 [[#5.2 封面图处理]]）      |
| 分类标签  | 标签  | 自由输入，简洁概括，同义合并。不预设分类，读什么建什么 |
| 阅读状态  | 单选  | 待读 / 在读 / 已读 / 重读           |
| 阅读方式  | 单选  | 自主阅读 / AI辅助                 |

**标签原则**：尽量简洁，同一含义只用同一个词。避免造近义词导致筛选不到一起去。

**新建视图筛选**：数据库支持创建多个视图，可按阅读状态、分类标签、阅读方式等条件筛选，不影响原卡片视图。

## 四、阅读双流程

### 流程 A：自主阅读

发现书籍 → 录入数据库（待读）→ 开始读（在读）→ 写入书摘笔记（摘抄+想法）→ 有价值内容流入待处理笔记/随笔（标注 `[[书名]]`）→ 读完（已读，填日期+概述）→ 提炼精华 → 写入常青笔记（标注来源）→ 双向链接回数据库

### 流程 B：AI 辅助阅读

发现书籍 → 录入数据库（待读，方式=AI辅助） → AI 通读输出框架+要点+重点章节 → 存入 AI 书摘笔记（`书名-AI.md`，与个人书摘分离）→ 带着问题去读（在读）→ 写入个人书摘笔记（`书名.md`，对照 AI 书摘 + 自己的思考）→ 有价值内容流入待处理笔记 → 读完（已读） → 提炼 → 写入常青笔记

**书摘文件命名规则**：

| 类型 | 文件 | 说明 |
|------|------|------|
| AI 书摘 | `个人迭代/图书馆/书摘/书名-AI.md` | AI 生成的框架、要点、重点章节 |
| 个人书摘 | `个人迭代/图书馆/书摘/书名.md` | 自己阅读时的摘抄 + 思考 |

两者不共用同一文件，便于区分 AI 提炼的内容和自己消化的内容。

**AI 输出格式**：

| # | 板块 | 说明 |
|:--:|------|------|
| 1 | 一句话定位 | 这本书解决什么问题、作者的核心主张 |
| 2 | 知识框架图 | 全书骨架，2-3 层树状。按知识归属重组逻辑，非章节目录 |
| 3 | 核心概念表 | 关键术语 + 一句话定义。天然是常青笔记的种子 |
| 4 | 方法论/模型 | 书中可操作的方法、步骤、思维框架。日后真正复用的东西 |
| 5 | 重点章节导航 | 标注 2-4 章建议精读 + 理由 + 对应该章的概念/方法条目 |
| 6 | 可略过章节 | 一笔带过，避免在水分章节上浪费时间 |

**使用逻辑**：先看 1+2 判断值不值 → 看 3+4 看有什么可拿走的 → 看 5 决定精读哪些章 → 带着 3/4 的框架去读，在个人书摘 `书名.md` 里验证、反驳、补充。板块 3/4 的条目确认有效后直接提入待处理笔记/常青笔记。如有思维导图等其他需求另行讨论。

## 五、PDF 阅读与批注实操

### 5.1 阅读方式

采用**手动记录**：边读边在 `个人迭代/图书馆/书摘/书名.md` 里按 [[模板/书摘模板]] 格式打字记录摘抄和想法，不依赖任何批注工具。

**书摘要克制**：只记核心观点和自己的思考，不复制大段原文。

### 5.2 封面图处理

数据库卡片视图显示封面图，操作步骤：

1. **找封面**：网上搜索书名+封面，下载 JPG/PNG
2. **放位置**：把封面图放到 `个人迭代/图书馆/书籍附件/` 下
3. **YAML 引用**：在元数据笔记 frontmatter 中加一行
   ```yaml
   cover: "[[个人迭代/图书馆/书籍附件/封面图文件名.jpg]]"
   ```
4. **显示**：Bases 卡片视图自动提取并显示

**示例**：
```yaml
---
书名: 小岛经济学
作者: 彼得·希夫 / 安德鲁·希夫
分类标签:
  - 经济理财
阅读状态: 待读
阅读方式: 自主阅读
cover: "[[个人迭代/图书馆/书籍附件/小岛经济学封面.jpg]]"
---
```

## 六、与现有系统的联动

| 系统      | 联动方式                             |
| ------- | -------------------------------- |
| PDF 阅读  | 在 Obsidian 内打开 PDF 阅读，摘抄手动记入书摘笔记 |
| 待处理笔记   | 书摘笔记中的有价值内容流入待处理笔记               |
| 常青笔记    | 读完后的提炼、方法论、核心观点                  |
| Tracker | 不追踪每月读完几本书，以深度和产出为导向             |

**书摘笔记的流向**：

```
阅读中记录摘抄与想法
      ↓
写入书摘笔记 → 个人迭代/图书馆/书摘/书名.md
      ↓
有价值内容流入待处理笔记/随笔
      ↓
读完后提炼精华
      ↓
写入常青笔记（标注来源 [[书名]]）
```
