# 蒜蓉粉丝虾

## 用料
| 材料   | 用量      | 图示  | 备注  |
| ---- | ------- | --- | --- |
| 虾    | 20~25 个 | [[个人迭代/菜谱/菜谱附件/蒜蓉粉丝虾/虾.jpg\|虾]] |     |
| 大蒜   |         | [[个人迭代/菜谱/菜谱附件/蒜蓉粉丝虾/大蒜.jpg\|大蒜]] |     |
| 小米辣  |         | [[个人迭代/菜谱/菜谱附件/蒜蓉粉丝虾/小米辣.jpg\|小米辣]] |     |
| 粉丝   |         | [[个人迭代/菜谱/菜谱附件/蒜蓉粉丝虾/粉丝.jpg\|粉丝]] |     |
| 青蒜苗  |         |     | 出锅用 |
| 配料   |         |     | 生抽、老抽、蚝油、料酒、盐、糖、白胡椒、淀粉 |

## 步骤

| 步骤  | 详情                                                     | 图示                                        | 备注                          |
| :-: | ------------------------------------------------------ | ----------------------------------------- | --------------------------- |
|  ①  | 处理虾：去虾头、去虾线、去虾壳。买虾仁则无需处理                               |                                           |                             |
|  ②  | 做蒜末，和小米辣放在一起                                           | [[个人迭代/菜谱/菜谱附件/蒜蓉粉丝虾/蒜末，辣椒段.jpg\|蒜末，辣椒段]] |                             |
|  ③  | 调配酱料：生抽 4勺、老抽 1 勺、蚝油少许、料酒 2 勺、盐半勺、糖半勺、少许白胡椒、半勺淀粉，加清水搅拌 |                                           | 白胡椒少放点                      |
|  ④  | 加多一点油，烧热后把虾煎好，盛出备用                                     |                                           | 多煎一会儿，肉紧实一点                 |
|  ⑤  | 剩下的油下蒜末，出香味后放小米辣翻拌；不要等蒜末焦了，放入处理好的虾                     |                                           | 蒜末较小，需快速翻拌防止糊锅              |
|  ⑥  | 放料汁，开小火慢煮，让虾充分吸收味道；快出锅时放青蒜苗                            |                                           | 可以多放点水多煮一会儿，充分吸收味道          |
|  ⑦  | 虾和一半料汁盛入盘中；剩一半料汁加少许水，小火煮粉丝至软                           |                                           | 粉丝吸汁强，分走一半避免虾那边没味道，多煮一会煮软一点 |
|  ⑧  | 摆盘：粉丝铺盘底，虾和另一半酱汁放粉丝上面                                  |                                           |                             |
