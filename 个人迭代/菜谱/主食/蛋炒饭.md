# 蛋炒饭

## 用料
| 材料   | 用量    | 图示  | 备注  |
| ---   | ----- | --- | --- |
| 隔夜剩饭 | 适量    |     |     |
| 鸡蛋   | 1~2 个 |     |     |
| 火腿肠  | 2 根    |     |     |
| 小葱   | 少许    |     | 撒面用 |
| 配料   |       |     | 盐、生抽、老抽 |

## 步骤

| 步骤  | 详情                                           | 图示  | 备注       |
| :-: | -------------------------------------------- | --- | -------- |
|  ①  | 鸡蛋搅拌均匀，加少许盐搅匀                                |     |          |
|  ②  | 油烧热，倒入蛋液，煎至成型                               |     |          |
|  ③  | 放入隔夜剩饭，按至饭均匀铺开；加入火腿肠                        |     |          |
|  ④  | 加少量生抽、老抽，快速翻拌均匀即可                           |     | 少量即可  |
|  ⑤  | 撒上少许葱花                                       |     |          |
